# Expense Calculator

## 📌 Overview
The **Expense Calculator** is a web-based expense tracking application developed using HTML, CSS, and JavaScript. It helps users manage their budgets, record daily expenses, categorize spending, and monitor their financial balance through a simple and user-friendly interface.

The application provides real-time expense calculations and uses browser Local Storage to retain data across page refreshes.

## ✨ Features
- **Budget Management:** Set and update a personal budget.
- **Add Expenses:** Record expenses with a name, amount, and category.
- **Expense Categorization:** Organize spending into Food, Travel, Shopping, Education, Bills, and Others.
- **Expense History:** View all recorded expenses in an organized list.
- **Delete Expenses:** Remove individual expense records.
- **Real-Time Calculations:** Automatically calculate total expenses and remaining budget.
- **Local Storage:** Save budget and expense data in the browser.
- **Responsive Design:** Access the application across desktop and mobile devices.

## 🛠️ Technologies Used
- HTML5 – Structure and layout
- CSS3 – Styling and responsive design
- JavaScript – Application functionality and calculations
- Local Storage – Client-side data persistence

## 🚀 How to Run the Project

1. Clone this repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Set your budget and start recording expenses.
